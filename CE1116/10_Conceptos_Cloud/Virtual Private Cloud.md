## 📚 Idea/Concepto 
La Virtual Private Cloud (VPC), o Virtual Network (VNet) en Azure, es una emulación de la infraestructura de red física en la nube, diseñada fundamentalmente para ofrecer un entorno de red virtual lógicamente aislado.

La VPC es la unidad base para la aislación y segmentación de los recursos en la nube (como máquinas virtuales), permitiendo a los clientes gestionar, monitorear y asegurar la conectividad. Esta red se segmenta mediante subredes para la gestión eficiente de la asignación de direcciones IP y la aplicación de políticas de filtrado de tráfico, como los grupos de seguridad.

Está intrínsecamente limitada a una sola región. Las arquitecturas multirregión requieren múltiples VPCs, cuya interconexión se logra mediante mecanismos como VNet peering o VPN Gateway. Además de comunicar recursos internos, la VPC habilita el enrutamiento de tráfico y la conectividad cifrada con entornos on-premise.
